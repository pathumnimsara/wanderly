# 🌍 Wanderly

> A cinematic South Asia travel experience built with React.

Wanderly is a modern travel destination showcase website designed to make exploring South Asia feel immersive, visual, and inspiring.

The project focuses primarily on **UI/UX, visual storytelling, animations, smooth transitions, cinematic imagery, and responsive design** rather than complex travel-booking functionality.

🔗 **Live Demo:** https://wanderly-6333.vercel.app/

---

## ✨ Project Overview

Wanderly is a frontend travel experience platform created to showcase beautiful destinations across South Asia through a premium and immersive interface.

The website combines:

- Cinematic hero video
- High-quality destination imagery
- Smooth animations
- Interactive cards
- Page transitions
- Responsive layouts
- Clean typography
- Modern navigation
- Destination detail pages
- Experience discovery
- Simple trip planning interface

The goal is to create a website that feels more like a **digital travel experience** than a traditional travel website.

---

## 🎯 Main Goal

The main goal of Wanderly is to improve the **user experience of discovering travel destinations**.

Instead of focusing on complicated functionality, the project focuses on:

### 🎨 Visual Experience
Beautiful imagery, cinematic sections, large typography and carefully designed layouts.

### 🧭 User Experience
Simple navigation that allows users to move between destinations, experiences and pages naturally.

### ✨ Interaction
Hover effects, animations, motion elements and smooth visual feedback.

### 📱 Responsive Design
The interface adapts to desktop, tablet and mobile screen sizes.

### 🌏 Travel Storytelling
Destinations are presented through visual storytelling rather than only text and data.

## 🚀 Main Features

### 🎬 Cinematic Hero Section

The homepage starts with a full-screen travel video experience.

Features include:

- Background video
- Auto play
- Muted playback
- Looping
- Mobile-friendly video behavior
- Dark overlay for better text readability
- Large cinematic typography

---

### 🖼️ Destination Showcase

Destinations are displayed using large visual cards with:

- Destination image
- Country
- Location
- Category
- Description
- Hover animation
- Interactive navigation

---

### ✨ Motion & Animations

The project uses motion-based interactions to make the interface feel more dynamic.

Examples include:

- Card hover animations
- Image movement
- Arrow rotations
- Section animations
- Interactive buttons
- Smooth visual transitions

---

### 📱 Responsive UI

Wanderly is designed for:

- Desktop
- Laptop
- Tablet
- Mobile

The layout changes depending on screen size while maintaining the overall visual identity.

---

### 🧭 Multi-Page Navigation

The application includes:

- Discover
- Destinations
- Experiences
- About
- Plan My Trip
- Destination Details
- Experience Details
